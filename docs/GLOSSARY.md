# Project Glossary

This glossary explains common WorkSphere terms used throughout the documentation.

## Venue
A workspace, meeting room, or other reservable location that users can book through WorkSphere.

## Reservation
A confirmed booking of a venue for a specific date and time.

## Availability
The schedule that indicates when a venue is available for reservation.

## Multi-City Comparison
A feature that allows users to compare venues across multiple cities using filters and synchronized URL parameters.

## Background Sync
A mechanism that retries pending actions when network connectivity is restored, helping keep user data synchronized.

## PartyKit
The realtime collaboration infrastructure used for live updates and synchronization.

## AI Assistant
An AI-powered feature that helps users with recommendations and other supported tasks within WorkSphere.

## Notification Channels
The supported methods used by WorkSphere to deliver notifications, such as in-app alerts and push notifications.

## Reservation Concurrency
The strategy used to prevent conflicting bookings when multiple users attempt to reserve the same venue simultaneously.

## Offline Storage
The local storage mechanisms used to keep parts of the application functional when the device is offline.
