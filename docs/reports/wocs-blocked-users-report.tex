\section{Corrective Governance Actions Implemented (Nov 28, 2026)}
In full alignment with Code Social / WOCS guidelines, the following workflow changes have been deployed on \texttt{main}:
\begin{enumerate}[leftmargin=1.5em, itemsep=3pt]
  \item \textbf{Auto-Merge Paused:} Disabled automatic triggers (\texttt{pull\_request\_target}, \texttt{issue\_comment}, \texttt{workflow\_run}, and 5-minute \texttt{schedule}) in \texttt{.github/workflows/auto-merge.yml} and removed automated bot self-approvals so PRs cannot be merged without meaningful review.
  \item \textbf{Documentation Label Inflation Fixed:} Updated \texttt{.github/workflows/auto-comment.yml} and \texttt{.github/workflows/auto-label-new-issue.yml} so documentation-only PRs and \texttt{documentation} issues are \textbf{strictly capped at \texttt{level 1}}, preventing line-count or keyword heuristics from assigning \texttt{level 2} or \texttt{level 3}.
  \item \textbf{Transparent Moderation:} Documented all 5 blocked accounts in this report with verifiable GitHub permalinks.
\end{enumerate}
