# UI Documentation

Guides for WorkSphere's visual system: design tokens, theming, spacing, typography, and the glass and glow effects built on Tailwind CSS v4.

## Tokens, spacing and typography

- [Fluid Typography and Spacing Guide](./FLUID_TYPOGRAPHY_AND_SPACING.md): token hierarchy, the 4px spacing grid, `clamp()`-based fluid font sizes, WCAG 2.1 AA contrast ratios, and a CSS variable reference.
- [Theme Token Architecture](./THEME_TOKEN_ARCHITECTURE.md): the CSS variable dictionary, light, dark, Cyberpunk and high-contrast themes, and semantic token migration examples.
- [Design Tokens & Color Contrast Matrix](../design-system/DESIGN_TOKENS.md): full spacing, radius and type scale tables and the contrast matrix.

## Effects

- [Venue Action Glassmorphic Pulse Guide](./GLASSMORPHIC_PULSE_GUIDE.md): the glassmorphic pulse animation on venue action buttons.
- [Hard-Light Construct Glassmorphism Design Guidelines](./HardLightGlassmorphism.md): hard-light glassmorphism design rules.
- [Construct Glow CSS Utilities](./CONSTRUCT_GLOW_UTILITIES.md): GPU compositing and performance notes for the glow utilities.
